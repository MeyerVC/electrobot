Electrobot Electrónica y Robótica

Meyer Jhonatan Velasco Churata

El proyecto consistira en un sistema web local para una tienda de electrónica. Donde el propósito principal de esta página es mostrar una lista de componentes educativos y placas de desarrollo junto con el precio que cuesta cada componente a un inicio será utilizada únicamente para visualizar los precios de manera más dinámica y así facilitar la consulta de precios dentro de la tienda física. Más adelante este proyecto se convertirá en un sistema completo y online para comercio electrónico.

  • Placa Arduino Uno R3
  • Módulo Bluetooth HC-05
  • Sensor Ultrasónico HC-SR04
  • Placa de Desarrollo ESP32
  • Kit de Resistencias
  • Servomotor SG90
